# M-104 焚化者侦察车 (Incinerator FRV) 伴生独立战备 Mod

> **版本**：v3.2.0 (伴生独立战备架构)  
> **依赖**：Bingus Shared Loader v16+ (API 1)  
> **核心特性**：**原生伴生战备加载 + 独立网络通道 + 零客机闪退 (Zero Guest Crash)**

---

## 一、 功能介绍

在《绝地潜兵 2》中，**M-104 喷火侦察车（带车顶重型喷火器、尖刺撞角与重型装甲）**是一个数据完整但尚未正式上架舰船购买终端的载具。

本 Mod 彻底摒弃了老版本“暴力替换 M-102 载荷导致客机闪退”的做法，采用**官方原生的伴生战备引擎机制（Companion Stratagem）**：
1. **飞船正常选择**：在舰船整备界面正常装备【M-102 侦察车】；
2. **伴生自动挂载**：进入任务后，战备菜单中会**额外独立加载出【M-104 焚化者侦察车】**战备选项；
3. **独立搓码呼叫**：
   - **M-102（原版机枪车）**：依然完好保留，呼叫按原版；
   - **M-104（喷火侦察车）**：官方原生呼叫代码：**`↓ → ↑ ↓ → ← ←`**；
4. **全员联机零闪退**：不管是单人、好友组队，还是匹配未装 Mod 的纯净路人客机，**全员均不闪退、完美同步**！

## 二、 为什么老版本替换会闪退，新版本如何解决？

### 1. 老版本替换导致闪退的病根
- 旧版替换 Mod 只是偷换了生成车辆的 `payload`（车辆哈希），但网络广播出去的战备 ID 依然是 M-102；
- 未装 Mod 的普通客机收到 M-102 的战备通知后，本地按机枪车分配资源；
- 随后房主端同步下来带有重型喷火器与尖刺的 `frv_heavy` 实体，客机端在解析喷火器骨骼和部件插槽时**遭遇空指针（NULL Pointer Dereference）**，在 `game.dll + 0x6F94C1` 产生 `0xC0000005` 异常崩溃！

### 2. 本版本的彻底解决之道（伴生战备）
- 借鉴官方【飞鹰系列】携带后自动赠送【飞鹰重新武装】的机制；
- 利用 `StratagemSettings` 表中记录的 `+200` 偏移（`additional_stratagem` 伴生挂载字段），将 M-102 的伴生指向 M-104（类型 135）；
- M-102 原车的数据、包、实体 100% 保持纯净出厂状态；
- M-104 作为独立的战备网络广播，客机端直接调用游戏本体自带的 Record 2 原生资源树进行同步，**彻底杜绝了模型骨骼错位，实现 100% 稳定联机**。

## 三、 安装与使用

### 安装方法
1. 下载打包好的发布文件：`M104-FRV-Unlock-3.0.0.zip`；
2. 打开 **HD2 Mod Manager**，导入该压缩包并点击 **Deploy**。

### 游戏内使用
1. 在舰船的 4 个战备槽位中装备 **【M-102 侦察车】**；
2. 进入对局（单人或多人均可）；
3. 按住 `Ctrl` 打开战备菜单，在常驻战备列表中会看到独立的 **M-104 喷火战车** 选项；
4. 输入战备按键指令：
   $$\downarrow \rightarrow \uparrow \downarrow \rightarrow \leftarrow \leftarrow$$
   （下、右、上、下、右、左、左）
5. 运输机会立刻空投下完整的 **M-104 焚化者喷火侦察车**！
